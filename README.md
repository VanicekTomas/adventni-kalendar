# Adventní kalendář 2026

Webový generátor HTML listingů pro sérii 24 geocachingových adventních setkání pořádaných v Prostějově a okolí v prosinci 2026.

Umožňuje jednotlivým organizátorům připravit název eventu a jednotně graficky zpracovaný popis, včetně jeho průběžného náhledu.

Projekt vytvořil geocacher **bandita007**. Web funguje přímo v prohlížeči bez serverové části.
